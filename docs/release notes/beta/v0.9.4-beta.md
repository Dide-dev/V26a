# Release Notes v0.9.4-beta

*June 10, 2026*

This beta-release includes co-authors, tree duplication, e-mail verification, logging out and more.

## Features

### Trees

- Trees can now be duplicated.
    - Even if you are not the owner of the tree, you can duplicate it and subsequently edit it.
    - Trees can de duplicated from the tree list pages and the tree viewer page.
- Tree owners can now authorize other users as co-author.
    - Co-authors can edit any tree data. However, they cannot add other co-authors.
    - Two users cannot update a tree simultaneously, to prevent data loss.
    - When opening a tree in a new tab, a check is done whether anyone else is editing the tree as well.
      If this is the case, the user is prompted whether they want to force-kick the current editor,
      with a warning that this could result in a loss of unsaved changes.
- The layout of trees has been improved.
    - Tree branches may now be collapsed.
    - Each branch now has their own color.
    - Cards now automatically go out of focus when exploring further into the tree.
        - Users can manually override this behavior by clicking on the card.

### Account

- New users are now required to verify their e-mail before completing their registration.
- Users can now log out.
- Users can now delete their account.
    - When deleting their account, users are asked whether they want to delete all their trees as well.

## Fixes

- Fixed an issue where the page would freeze during rendering.
- The tree-viewer now redirects back to the tree list if no tree was queried.
- Fixed an issue where a non-logged in user would not be redirected back to their
  my-trees page after logging in.

## Technical

- Sessions are now saved in the database, such that they can be invalidated.
