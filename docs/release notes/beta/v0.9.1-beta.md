# Release Notes v0.9.1-beta

*May 20, 2026*

This second beta-release includes a tree-list page with basic filters, an enhanced tree-editor page
with support for Markdown- and KaTeX-syntax, an improved overall layout and more.

## Accounts

- Usernames have been made unique, and can no longer contain whitespaces,
  or certain other special characters.
- Users can change their password by providing their current password.

## Navigation

- The navigation bar layout has been improved.
    - On smaller screens, the navigation bar gets compacted into a hamburger menu.
    - A dropdown has been added to more logically sort links.
- The links in the navigation bar respond to the user's account status.
- A footer has been added, with links to various pages such as /privacy, /colophon, and more.

## Trees

- A tree list page has been added.
    - Trees can be filtered by creation date and owner id.
- The tree-editor has been improved with added functionality.
    - Cards support Markdown and KaTeX-syntax.
    - Images can be uploaded to a card.
    - Cards can be moved by dragging them.
    - Root nodes can be added, removed, swapped and edited.
    - The last few actions be undone and redone.

## Feedback

- A feedback page has been added where users can provide feedback on the website.

## Admin

- Admin permissions have been added.
- Admins can retrieve a list of all users.
- Admins can bypass certain restrictions.

## API Documentation

- API Documentation has been added on /api-docs/.
    - Can be accessed through the link in the footer.
