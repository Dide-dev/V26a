# Release Notes v0.9.3-beta

*June 3, 2026*

This beta-release includes new information for trees, the ability to create classrooms,
various bug fixes, and more.

## Features

### Trees

- Trees can now have tags, a language and a subject attached.
    - In the future, these will be used to help users find the correct tree.

### Classrooms

- You can now create classrooms, if you are logged in.
    - Classrooms do not yet have any functionality.

### Admin

- Admins can now change any user's data.
- Admins can view all feedback concerning the website.

## Fixes

- Fixed an issue where users with a short (less than 8 characters) password in the prototype could not log in.
  The password length is now no longer validated when logging in, to account for old, weaker passwords.
    - We do encourage users with weak passwords to update them to stronger ones on the profile-page.
- Fixed an issue where the tree-list page could produce an error when reducing the page size.
  Upon changing the page size, the user now gets sent back to the first page.
- Fixed an issue where the card editor could produce an error when using italic or bold fonts in math blocks.
  Italic and bold texts are now ignored in math blocks, and just handled as any normal text.
- Fixed an issue where some texts in the card editor were not localized.

## Technical

- All the API-endpoints have been changed to follow RESTful guidelines. Check all the new endpoint-paths on
  the [api-docs](https://boom.its.uu.nl/api-docs/).
- The `/trees/get-list`-endpoint has new filter functionalities.
- The API now has a rate limit on several endpoints to prevent misuse.
- The API now has minimum input lengths on certain fields.
