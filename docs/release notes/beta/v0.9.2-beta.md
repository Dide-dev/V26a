# Release Notes v0.9.2-beta

*May 28, 2026*

This beta-release includes a migration of all account and tree data of the [prototype](https://edspace.nl/htree/), a
visual text editor, a newly revamped home-page and more.

## API

- Input lengths of certain fields are now also validated in all API-requests.

## Home-page

- A home-page has been added, with quick info on the use and creation of heuristic trees on the website.

## Migration

- The data from the prototype website has been migrated into the new site.
    - Users can log into their previously created accounts.
    - All previously created trees can be accessed, and edited by their owners.

## Trees

- The tree-editor has been improved with a visual text editor, allowing for easy formatting.
    - The sidebar in which a card's contents are edited now contains a What You See Is What You Get visual editor, where
      buttons on the top allow formatting the text, inserting formula blocks, and more.
- The tree-viewer page displays more information on the tree, including the tree's tags, assignment and book
  information.
