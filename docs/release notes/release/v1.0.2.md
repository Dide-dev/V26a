# Release Notes v1.0.2

*June 23, 2026*

This release includes some updates and minor bugfixes.

## Update

- Some out-of-date packages of the back-end have been updated.

## Fixes

- The front-end now checks that the username is valid on the profile page, 
  preventing an error to be returned from the back-end.
- Multiple misspellings were fixed.
- The filters are applied properly when clicking on a tag or owner on the tree viewer page.
