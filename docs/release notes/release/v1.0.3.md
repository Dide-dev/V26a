# Release Notes v1.0.3

*October 13, 2026*

This release includes printing functionality and full-screen mode.

## Full-screen

- Full-screen mode has been added, which hides the navigation bar and footer. It can be toggled by pressing 'F', or
  exited by pressing 'Esc'.
- On the viewer page of a tree an extra button has been added to toggle full-screen mode on or off.

## Printing

- A button has been added to the viewer page, leading to the print page of the tree.
- The print page automatically enables full-screen mode, reveals all cards, showing both their front- and backsides.
- There's also an option menu allowing the size of the cards to be adjusted to match the correct post-it size.
- There's also an information menu with extra instructions on how to print the page.

## Home-page

- A new entry on how to print a tree has been added.

## Technical

- Rust has been upgraded to version 1.99.0.
