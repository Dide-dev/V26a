# Release Notes v1.0.0

*June 19, 2026*

This first full release includes a UI overhaul of tree filters and the tree editor, several new classroom pages, and more.
It also includes all features present in past beta releases.

## Features

### Trees

- The layout of the tree lists has been improved.
- Tree filters have been improved.
    - Trees can be filtered using tags, date, language, subject, book and/or owner.
    - Trees can be searched by title, description and assignment text.
- The layout of the tree-editor has been improved.
    - The colors now match the tree viewer.
    - A permanent sidebar has been added, with all the functionality to edit tree data, add and remove co-authors, and publish, share or delete the tree.
- Cards can now be added to the cards library, after which other authors can use them in their trees.

### Classrooms

- Added new pages for students, for joining classrooms and listing all joined classrooms.
- Added a new page for teachers, for listing all classrooms created by themselves.
- Added dashboard pages for both students and teachers.
    - On the teacher dashboard page, a teacher can add lessons to the classroom, and trees to the lessons.
      Teachers can also copy and share the join code to that classroom.
    - On the student dashboard page, a student can access a classroom with its trees sorted by lesson.


### Misc

- Users can reset their passwords using a reset link, which they receive via email.
- Added a new admin page for adding and updating available languages and subjects for trees.
- Added the privacy policy, terms and conditions, and colophon.
- Added a title and favicon to the website.

## Fixes

- Fixed an issue where a LaTeX-formula in the last line of a card would cause a scrollbar to appear in the card.
- Fixed an issue where entering duplicate tags when filtering trees or cards would result in an error. The duplicate tag is now ignored.

## Technical

- Improved rate limits, generally making them more lenient.
