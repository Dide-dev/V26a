# Release Notes v1.0.1

*June 22, 2026*

This second full release includes multiple refactors, including the change of some link routes. 
Besides, it adds the functionality to delete cards from the cards library.

## Features

### Trees

- Cards can now be removed from the cards library.
- The UI of the kick page has been made consistent with the theme of the website.
  This also fixed an issue where certain buttons would not correctly display whether they were clickable.
- On the tree pages, a button has been added to create a new tree.

## Refactoring

- The route (relative URL) of multiple pages of the website have been changed.
- On the back-end, we did some renaming.
